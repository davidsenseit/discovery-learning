# Visual learning strategy

status: draft

## Decision process
Start with **the learning objective and cognitive task**, not the available tool. Choose a visual only when it makes structure, comparison, movement, quantitative relationship or causality materially clearer than concise text.

| Task | Candidate representation | Evidence and correctness needs |
|---|---|---|
| Process/order | Simple flow diagram or stepwise annotated illustration | Correct sequence and branches |
| System relationships | Concept map or causal network | Defined nodes and accurate link semantics |
| Quantitative comparison | Bar/line/scatter chart | Units, scales, sources, uncertainty |
| Cause and effect | Single-variable interactive model | Transparent formula, units and bounds |
| Physical assembly or procedure | Labeled schematic or staged drawing | Accurate geometry, safety and constraints |
| Spatial orientation | Map or spatial diagram | Reliable locators, distances and directions |
| Concept memory callback | Previously introduced, simplified relationship diagram | Keep consistent terminology; vary applied scenario |

## Visual cognitive-load rules
- No decorative image quotas. If a picture adds no instructional information, omit it.
- Reveal complex systems progressively, using one relevant relationship at a time.
- Keep visual labels and explanatory text adjacent; use consistent terminology and meaningful alt descriptions.
- Do not convey correct/incorrect or risk solely through color.
- Check arithmetic, axes, labels and units separately from artistic quality.
- Never present speculative AI-generated scientific, legal or technical diagrams as verified.
- A static visual is often preferable to a complex interactive simulation when interaction adds no new insight.

## Multi-modal teaching sequence
Scene → useful representation → learner action/observation → grounded explanation → later recall/transfer.
A representation can serve both initial understanding and later memory retrieval. Avoid forcing a recall question immediately after every image.

## Interactivity and fallback
Specify the **educational behavior** independent of implementation. For an interactive chart, describe what value changes, what remains fixed, the function, expected consequences and how the learner accesses the same information as text. For a slider, include two or more worked comparison states in text. For a diagram, include an accessible numbered relationship list.

Rich visuals can be generated only when the current environment supports them. If the visual is unavailable, provide the equivalent text or tabular explanation and continue without requiring special controls.

## Validation
Test visual readability, interpretation, correctness, unnecessary mental load, accessibility and consistency against source material. A visual may be engaging but must still be pedagogically necessary.

## Documented categories
- Artifacts support standalone documents, diagrams, dashboards and small interactive tools.
- Claude Design supports creating interactive prototypes.
- Artifacts require appropriate settings and availability varies by environment, plan and organization.

## Use constraints
Do **not** assume an Artifact will be rendered in every Claude client or API runtime. Generating code is different from running an interactive tool in the learner's actual session. Record exact environment and test outcome.

## Revalidation
At a new course project, confirm up-to-date provider support, feature entitlements and environment. A text-only course must remain functional.

# Generic text-first platform profile

status: draft
checked_at: 2026-11-05

Assume basic text conversation only until a specific runtime capability is established.

Supports by design:
- Short introductory scene and factual explanation.
- A/B/continue exploration and prediction by text.
- Numbered process descriptions, plain tables, short calculations and comparisons.
- Natural concept callbacks, error correction and non-blocking progression.

Unknown until verified:
- Images, audio, rich formatted diagrams, code execution, clickable UI, stateful widgets, persistent memory, tools and web browsing.

This is a fallback contract, **not** a claim about any specific model or service.
